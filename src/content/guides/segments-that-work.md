Saved segments should be boringly reliable.

## Prefer explicit rules

Combine status, tags, engagement windows, and custom fields. Name segments after the job they do, not the query syntax.

## Trust live counts

Maildrill recalculates match counts as you edit. If the count looks wrong, the rule is wrong — fix it before save.

## Reuse across channels

The same segment can power email today and SMS tomorrow. That is the point of one shared audience.
